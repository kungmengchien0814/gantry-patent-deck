## 講者視窗與備答卡

- **講者視窗（P）**：另開一個視窗，放在自己的螢幕上，投影只投主畫面。顯示目前這一步的字幕、本頁完整講稿、下一步／下一頁預告（換人時會提示）、本頁備答與備註，以及計時器：翻頁就自動開始，會顯示本頁用時和「超前／落後」。講者視窗裡按 ← → 也能翻主畫面。瀏覽器若擋下彈出視窗，請允許本網站開啟。
- **備答卡（Q）**：15 題可能被問的問題，每題約 30 秒的回答，標示「有依據／推論／待驗證／待補」；和目前這頁有關的題目號碼會變橘色，點「第 n 頁」可直接跳過去。
- **差異矩陣（第 5 頁）**：點任一格會跳出該前案的段落或請求項出處、內容摘要，以及原文連結。

## 內容

8 站（封面＋7 章），頁碼與原 pptx 相同：

| 章 | 頁 | 內容 |
|---|---|---|
| 01 選題動機 | 2 | 開場互動（熱變位占幾成）、上熱下冷造成傾斜、延續 CSME2025 研究 |
| 02 市面與前案 | 3–5 | 市面四種做法、先前技術比對＋台灣前案檢索、差異矩陣（可點出原文依據） |
| 03 改善方法 | 6 | 規則單 6 類中用到 5 類 |
| 04 系統與控制 | 7–8 | 系統構成與符號、均溫控制流程（雙門檻控制示意） |
| 05 創新與驗證 | 9–10 | 三個創新點、COMSOL 模擬選點 |
| 06 申請專利範圍 | 11–13 | 請求項 1、附屬項與方法項、保護參數 |
| 07 預期功效 | 14–15 | 預期功效、結語 |

右側 3D 龍門模型與第 8 頁的控制模擬都是**示意**：模型比例大致參考 COMSOL 模型、變形量大幅放大；控制模擬的溫度與流量是設定的示意值，不是實測或模擬結果；第 14 頁「控制後」為預期效果，溫差控制的改善率仍待模擬驗證。
