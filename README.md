# 龍門溫差式均溫系統｜專利互動簡報

龍門加工機之溫差式均溫系統及其方法：專利分析（115-1）期末小組報告的 15 頁互動簡報網站版。

網址：https://kungmengchien.uk/gantry-patent-deck/

四智四丙｜發明人：龔孟謙、周大凱、鄭楷諺、陳宣佑

## 內容

8 站（封面＋7 章），頁碼與原 pptx 相同：

| 章 | 頁 | 內容 |
|---|---|---|
| 01 選題動機 | 2 | 熱變位、上熱下冷造成傾斜、延續 CSME2025 研究 |
| 02 市面與前案 | 3–5 | 市面四種做法、先前技術比對、差異矩陣 |
| 03 改善方法 | 6 | 規則單 6 類中用到 5 類 |
| 04 系統與控制 | 7–8 | 系統構成與符號、均溫控制流程（雙門檻控制示意） |
| 05 創新與驗證 | 9–10 | 三個創新點、COMSOL 模擬選點 |
| 06 申請專利範圍 | 11–13 | 請求項 1、附屬項與方法項、保護參數 |
| 07 預期功效 | 14–15 | 預期功效、結語 |

右側 3D 龍門模型與第 8 頁的控制模擬都是**示意**：模型比例大致參考 COMSOL 模型、變形量大幅放大；控制模擬的溫度與流量是設定的示意值，不是實測或模擬結果；第 14 頁「控制後」為預期效果，溫差控制的改善率仍待模擬驗證。
